# HDFC AI Platform (capstone review app)

Governed pipeline from approved banking data to a served, fine-tuned assistant: datasets, training runs,
evaluation, approvals, model registry with rollback, and an assistant gateway with guardrails and citations.

Sign in with the demo accounts provided with the submission. See `MODEL_CARD.md` for the model's intended use,
evaluation and limitations. Source code and full documentation are in the project's GitHub repository.
